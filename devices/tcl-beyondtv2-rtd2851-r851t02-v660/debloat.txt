# TCL BeyondTV2 profile — debloat list (Android TV 9, R851T02 V660)
# Format compatible with upstream tools/disable.sh and tools/restore.sh (one package per line, # comments).
#
# Test date: 2026-10-18/19. Each package below was disabled ALONE with scripts/tcl-try-disable.sh,
# then the smoke test passed 24/24 and the device rebooted 3 times without problems.
# Measured effect: these removed processes but gave NO measurable overall speed gain
# (CPU idle and app-open times stayed within run-to-run noise). They are kept for less
# telemetry/ads, NOT for speed. Do not expect a speed-up from this list.
#
# NOTE ON TESTING TIME: each package was verified over a single session (disable -> smoke test ->
# reboots -> live use), NOT over several days. Treat this list as "verified to survive reboots and
# the smoke test", not as "verified over days of daily use". Upstream's CONTRIBUTING asks for
# days of use; this profile does not yet meet that bar and says so.
#
# Apply (one at a time is recommended):  bash scripts/tcl-try-disable.sh <package>
# Undo:                                   adb shell pm enable <package>
#
